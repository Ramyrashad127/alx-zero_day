# 0x03. Git

## Description
This module strengthens version control proficiency using **Git** and **GitHub**:
- Branch management (`git checkout -b`, `git merge`, `git branch -d`).
- Remote origin configuration (`git remote add origin`).
- Collaborative pull request and conflict resolution patterns.
- Proper `.gitignore` usage to avoid tracking temporary files.

## Files
- `bash/`: Scripts practicing bash syntax and repo file manipulation.
- `c/c_is_fun.c`: Simple C source verifying compiler setup.
